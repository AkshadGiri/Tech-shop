# Tech-Shop

Tech-Shop is a modern e-commerce web application built with React that allows users to browse technology products, view product details, add items to the cart, and enjoy a responsive shopping experience.

## Features

* Browse tech products
* Product details page
* Shopping cart functionality
* Responsive design
* Modern React-based UI

## Tech Stack

* React.js
* JavaScript
* CSS


## Run the Project

1. Clone the repository:

```bash
git clone https://github.com/AkshadGiri/Tech-shop.git
```

2. Navigate to the project folder:

```bash
cd Tech-shop
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in the terminal.
